# behavior_analysis
Package to perform behaviour analysis of worm under wbfm conditions, and hopefully also flexible to do the same on OpenAutscope of Epifluorescence recordings

## Content
Contains the notebook to convert manual behaviour annotation to timeseries.
```
start,end,beh
1,14,Fwd
15,34,Rev
35,59,Coil
```
(before it used to be in the centerline package see https://github.com/ulisesrey/behavior_analysis/commit/f0bbbb2b3b60714450682e87cd9c903b21c18a84)
