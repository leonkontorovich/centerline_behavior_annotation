# Centerline Behavior Annotation

This pipeline is used to annotate the behavior of the centerline of a worm. 
The centerline is used to further annotate:
1. Reversals
2. Turns
3. Speed
4. Full kymograph

## Organization of the repository

This repo was originally 5 different repositories, and has been combined.
The top level folders have been kept.
Please see individual README files for more information.

The main starting point for running the full pipelines is the "pipeline_cluster" folder.
